# DigitalCamera
This project simulates a basic digital camera systems using Arduino. The system detects motion using a PIR sensor and captures an image trigger event. When motion is detected, the system displays a capture message on the LCD and activates an indicator LED. 
## Components Used
- Arduino Uno
- PIR Motion Sensor
- 16*2 LCD display
- LED
- Resistor(220 ohms)
- Breadboard
- Jumper wires
